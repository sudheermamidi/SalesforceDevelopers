# Mock Interview Sets

## Round 1: Apex and Platform

1. Explain order of execution.
2. Refactor a non-bulkified trigger.
3. Design a retry strategy for failed callouts.
4. Explain sharing and FLS enforcement.
5. Write a test strategy for a trigger, service class, and Queueable job.

## Round 2: LWC

1. Build a component to show and update Case records.
2. Explain wire versus imperative calls.
3. Debug a component that does not refresh after DML.
4. Explain parent-child event communication.
5. Secure an Apex controller used by LWC.

## Round 3: Solution Design

Scenario: A healthcare company needs a patient support portal with appointment
questions, case creation, and automated care-plan reminders.

Discuss:

- Object model.
- Security and consent.
- LWC and Experience Cloud UI.
- Agentforce assistant and human handoff.
- Integration with external appointment system.
- Monitoring, deployment, and testing.

## Round 4: Cloud Specialization

Pick one:

- Sales Cloud pipeline modernization.
- Service Cloud contact-center migration.
- Marketing Cloud onboarding journey.
- Health Cloud patient intake.
- OmniStudio guided selling.
