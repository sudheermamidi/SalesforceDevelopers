# Hands-On Exercises

Each exercise is interview oriented. Build the solution, document assumptions, write
tests, and prepare a two-minute explanation.

## Exercise 1: Bulkified Contact Update

Create an Apex trigger that updates Contact status when Account tier changes.

Expected topics: trigger framework, bulkification, test data factory, partial failure.

## Exercise 2: Case Triage Console

Build an LWC that displays urgent Cases, shows SLA status, and lets an agent claim a
case. Secure Apex with sharing, CRUD, and FLS checks.

Expected topics: wire service, imperative Apex, LDS, security, UI state.

## Exercise 3: Agentforce Healthcare Assistant

Design an Agentforce agent for patient appointment support.

Expected topics: topics, actions, grounding, consent, audit, human handoff.

## Exercise 4: OmniStudio Claim Intake

Build an OmniScript plus FlexCard design for an insurance claim intake flow.

Expected topics: OmniScript steps, DataRaptors, Integration Procedures, deployment.

## Exercise 5: Sales Cloud Duplicate Strategy

Design duplicate rules, matching rules, Apex fallback, and reporting for Lead intake.

Expected topics: duplicate management, lead conversion, data quality.

## Exercise 6: Marketing Cloud Journey

Design a welcome journey that segments customers, sends personalized emails, and syncs
engagement back to Sales Cloud.

Expected topics: data extensions, subscriber key, journey entry source, API events.
