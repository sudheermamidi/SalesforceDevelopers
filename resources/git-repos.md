## How to Study Repositories

1. Clone the repo.
2. Read the README and project structure.
3. Identify Apex classes, LWCs, permissions, and deployment metadata.
4. Run tests.
5. Explain one feature as if you built it.
6. Modify a small behavior and document the change.
